# 🎰 KaiqueBet — A Casa de Apostas Oficial da Resenha!

Um site de apostas satírico e interativo criado 100% por brincadeira para se divertir com os amigos, **sem envolver nenhum centavo ou dinheiro real**. Todas as transações usam a moeda fictícia **KaiqueCoins (KC$)**!

---

## 🌟 O que tem no KaiqueBet?

1. ⚽ **Apostas da Resenha (Sportsbook dos Cria):**
   - Eventos do cotidiano e do grupo de amigos (ex: "O Kaique vai furar o churrasco?", "O amigo vai mandar o comprovante do pix?", "Solteiros vs Casados no campinho").
   - Cotações (odds) dinâmicas, bilhete de aposta lateral interativo e botão **🎲 Simular Resultado Agora** para resolver a aposta na hora.

2. 🚀 **Foguetinho do Kaique (Crash Game):**
   - Jogo crash em tempo real onde o foguete sobe e o multiplicador aumenta a cada fração de segundo!
   - Encerre sua aposta (*Cash Out*) antes do foguete explodir para embolsar o lucro.

3. 🐯 **Tigrinho Oficial do Kaique (Slot Machine):**
   - Caça-níquel de 3 rolos temático (👑 Coroa, 🐯 Tigrinho, 🍕 Pizza, 🍺 Litrão, 🚗 Uno com Escada, 🤡 Caloteiro).
   - Animação de giro e premiações em cascata.

4. 💸 **Banco Kaique S/A (Recarga Ilimitada):**
   - Zerou a banca? Basta clicar em **➕ Recarregar** para pedir um empréstimo fictício sem juros!

5. 🔊 **Efeitos Sonoros Retrô:**
   - Sons gerados nativamente no navegador usando a *Web Audio API* (bipes de vitória, giro, derrota e decolagem).

6. 💾 **Saldo Salvo:**
   - O saldo de KaiqueCoins e o histórico ficam salvos no seu navegador via `localStorage`.

## 🚀 Como abrir e rodar no VS Code

### Opção 1: Abrir diretamente no navegador (Mais fácil)
1. No VS Code ou no seu Explorador de Arquivos, encontre a pasta:
   `c:\Users\mauri\OneDrive\Desktop\KaiqueBet`
2. Dê **dois cliques** no arquivo [`index.html`](file:///c:/Users/mauri/OneDrive/Desktop/KaiqueBet/index.html).
3. O site abrirá automaticamente no seu navegador padrão (Chrome, Edge, etc.)!

### Opção 2: Usando a extensão Live Server no VS Code
1. Abra a pasta `KaiqueBet` no VS Code:
   - Vá no menu **Arquivo > Abrir Pasta...** e selecione `KaiqueBet` no Desktop.
2. Na barra de extensões do VS Code (`Ctrl + Shift + X`), procure por **Live Server** (de Ritwick Dey) e instale se desejar.
3. Clique com o botão direito sobre [`index.html`](file:///c:/Users/mauri/OneDrive/Desktop/KaiqueBet/index.html) e selecione **"Open with Live Server"**.

## ✏️ Como personalizar as apostas com os seus amigos

Para adicionar novas perguntas de brincadeira ou mudar as existentes:
1. Abra o arquivo [`app.js`](file:///c:/Users/mauri/OneDrive/Desktop/KaiqueBet/app.js).
2. Procure pela lista `INITIAL_BETS` (por volta da linha 90).
3. Você pode alterar as perguntas, odds e respostas à vontade!
